# RFV Analytics

Aplicação desenvolvida em Python e Streamlit para análise e segmentação de clientes utilizando o modelo RFV (Recência, Frequência e Valor).

### Funcionalidades
- Upload e visualização de arquivos CSV.
- Cálculo de Recência, Frequência e Valor por cliente.
- Classificação por quartis e geração do RFV Score.
- Segmentação de clientes por comportamento de compra.
- Recomendações de ações de marketing e CRM.
- Exportação dos resultados para Excel.

### Tecnologias
Python · Streamlit · Pandas · NumPy

### Executar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

Utilize o arquivo CSV disponível no repositório para testar a aplicação.
